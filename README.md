HealthMate is a personal and family health tracking web application designed to help users manage essential health records in one place. With support for tracking multiple family members under a single account, users can log and monitor blood pressure, blood sugar levels, vaccination schedules, doctor appointments, and medicine reminders for each family member. HealthMate provides a convenient and centralized platform for keeping track of your entire household’s health.

## 🚀 Features

- Single account supports tracking for the entire family
  
- Register and manage multiple family member profiles
  
- Add and view blood pressure and sugar readings per member
  
- Track vaccination schedules with upcoming due dates
  
- Schedule doctor appointments and view appointment history
  
- Set medicine reminders individually for each family member
  
- Responsive UI built with Bootstrap
  
- RESTful backend using Express.js and Node.js
  
- Secure data storage and management using MySQL

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript, Bootstrap
  
- Backend: Node.js, Express.js
  
- Database: MySQL
  
- Development Tools: Visual Studio Code
